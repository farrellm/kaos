# KAOS (Netflix TV Series) - Transcripts & Subtitles

## Series Bible

Analytical reference built from these transcripts, as groundwork for a Season 2
novelization. Ten Markdown files in [`bible/`](bible/):

| File | Contents |
|---|---|
| [00-OVERVIEW.md](bible/00-OVERVIEW.md) | Premise, tone, and a state-of-play table for every character at the S1 curtain |
| [01-CHARACTERS.md](bible/01-CHARACTERS.md) | Dossiers — role, wound, arc, exit position, voice |
| [02-COSMOLOGY.md](bible/02-COSMOLOGY.md) | Meander water, the Frame, the Nothing, prophecy, the limits of divinity |
| [03-EPISODES.md](bible/03-EPISODES.md) | Beat-by-beat breakdown of all eight episodes |
| [04-TIMELINE.md](bible/04-TIMELINE.md) | Kronos's death through to the final scene |
| [05-MYSTERIES.md](bible/05-MYSTERIES.md) | Resolved / partially resolved / open threads, with resolution constraints |
| [06-OLYMPUS.md](bible/06-OLYMPUS.md) | The divine power structure |
| [07-UNDERWORLD.md](bible/07-UNDERWORLD.md) | The bureaucracy of death |
| [08-EARTH-POLITICS.md](bible/08-EARTH-POLITICS.md) | Krete, Troy, the Amazons, Athens |
| [09-VOICE-AND-STYLE.md](bible/09-VOICE-AND-STYLE.md) | Narration, tonal register, dialogue idiom, structural habits |

Start with [00-OVERVIEW.md](bible/00-OVERVIEW.md). Claims the show states outright are
stated plainly; conclusions drawn from implication are marked **(inference)**.
