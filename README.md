# KAOS (Netflix TV Series) - Transcripts & Subtitles

Transcripts and subtitles for all 8 episodes of **KAOS** Season 1 (Netflix 2024, created by Charlie Covell, starring Jeff Goldblum).

## Directory Structure

```text
kaos/
├── download_transcripts.py        # Python downloader and processor script
└── transcripts/
    ├── KAOS_Season_1_Complete.txt # Full season transcript in a single file
    ├── txt/                       # Clean dialogue transcripts (plain text)
    │   ├── KAOS_S01E01.txt
    │   ├── KAOS_S01E02.txt
    │   ├── KAOS_S01E03.txt
    │   ├── KAOS_S01E04.txt
    │   ├── KAOS_S01E05.txt
    │   ├── KAOS_S01E06.txt
    │   ├── KAOS_S01E07.txt
    │   └── KAOS_S01E08.txt
    ├── md/                        # Formatted Markdown transcripts
    │   ├── KAOS_S01E01.md
    │   ├── KAOS_S01E02.md
    │   ├── KAOS_S01E03.md
    │   ├── KAOS_S01E04.md
    │   ├── KAOS_S01E05.md
    │   ├── KAOS_S01E06.md
    │   ├── KAOS_S01E07.md
    │   └── KAOS_S01E08.md
    └── srt/                       # Raw SRT subtitle files (with timestamps)
        ├── KAOS_S01E01.srt
        ├── KAOS_S01E02.srt
        ├── KAOS_S01E03.srt
        ├── KAOS_S01E04.srt
        ├── KAOS_S01E05.srt
        ├── KAOS_S01E06.srt
        ├── KAOS_S01E07.srt
        └── KAOS_S01E08.srt
```
